## Watch for in phase 8

- Generated shadcn files (`src/web/components/ui/**`) will break `no-comments`, `no-unsafe-as`, `context-terms` and possibly the seams rules. Turning rules off for them is a loosening: show the user the exact override and the `docs/lint-opt-outs.md` entry, and commit with the trailer only after a yes. Baselining them instead needs no approval; offer both.
- The web app is browser code: decide whether `src/web/` is a module (with `web.ts` entries per the overview) or sits outside `src/modules/`, and add seams rules so browser code cannot import `adapters.ts` or `node:*`. Changing `.dependency-cruiser.cjs` is flagged by the guard and needs the trailer.
- New devDependencies (Vite, React, Tailwind) change `package.json`; only the check scripts (`lint`, `verify` and kin) are guarded. Adding a `build` or `board` script is not flagged. Changing `verify` is.
- `src/cli/tkitchen.ts` must keep its path (the installer and verify-tkitchen call it).
